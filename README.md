The project is about creating a lab reservation system fully developed with client-server architecture and following model-view-controller architecture

To start the server:
    1. Type into command prompt with the root folder as directory, "npm install" which allows you to download the dependencies necessary for the server to run
    2. Then type "npm start" to start the server itself
    3. go to the browser and type http://localhost:3000 to see the website start

To start developing:
    1. Download the dependencies by running "npm install"
    2. Download MongoDB and connect it to your local machine
    3. Run "node init_db" to insert some initial data into the database (users and labs)
    4. Run "node server.js" to start the server
    5. Go to a browser, and go to "http://localhost:3000" to see the website live
